# Sistema de Pagos Digitales en Java

Proyecto desarrollado en Java para practicar los conceptos de Programación Orientada a Objetos (POO), simulando distintos métodos de pago dentro de una misma estructura de clases.

## Qué hace este programa
- Modela una clase base para los pagos y subclases específicas según el tipo de pago.
- Utiliza un arreglo polimórfico para almacenar y procesar distintos objetos de pago en conjunto.
- Aplica encapsulamiento (atributos privados con métodos `get` y `set`), herencia y sobrescritura de métodos (`@Override`).

## Requisitos y ejecución
- Tener instalado **Java (JDK)** y un editor como **Visual Studio Code**.
- Descargar los archivos `.java` en una misma carpeta, compilar y ejecutar la clase principal (`main`) para ver los resultados en consola.
